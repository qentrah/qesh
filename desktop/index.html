Commands

qh commands

Run qh help in a shell to list commands, or qh search to find one.

qh                       Help inside Qesh; start outside it
qh help                  Available commands
qh search [text]         Find commands
qh diagnostics           Check local storage and app metrics
qh config                Open configuration in your editor
qh update --check        Check for a release
qh update                Update a managed install
qh update-all --dry-run  Preview configured CLI updates
qh update-all            Run configured updates
qh workspace list        List saved workspaces
qh workspace NAME        Open a saved workspace
qh COMMAND               Run your custom command
